# Security Policy

## Supported versions

Security fixes are made for the current major version only.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| 0.x     | No        |

## Reporting a vulnerability

Please do not report security problems in a public issue, pull request or discussion.

Report them privately with GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab: <https://github.com/KashyapRajpal/Sabercat/security>.
2. Choose **Report a vulnerability**.
3. Describe the problem, the version or commit you tested, the steps to reproduce it, and its possible impact.

The maintainer will acknowledge the report, check it, and keep you informed while it is fixed. Once a fix is released, the advisory is published with credit to the reporter, unless you ask to stay anonymous.

Problems in third-party components are best reported to their own projects. Listed components are in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
